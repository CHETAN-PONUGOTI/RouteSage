# Safiri Route Intelligence

An explainable multi-objective shipment route decision platform.

## Overview
Safiri Route Intelligence is a decision-support system operating under competing objectives and uncertainty. It helps logistics planners evaluate and select shipment routes by balancing cost, transit time, reliability, and risk.

## Architecture
- Frontend: Next.js, React, Tailwind CSS, shadcn/ui
- Backend: Python, FastAPI, Pydantic, SQLAlchemy
- Database: PostgreSQL
